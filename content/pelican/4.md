# 들어가며
Pelican에 플러그인을 붙이면서 삽질을 꽤 했다.

이 글에서는 플러그인을 추가하는 방법과, 내가 실제로 사용한 플러그인들을 정리한다.

---

# 1. Pelican Plugin
## 1.1 공식 저장소
요즘 플러그인들은 [pelican-plugins organization](https://github.com/pelican-plugins)에서 각각 독립 저장소로 관리된다.

예전 방식의 플러그인 모음은 [getpelican/pelican-plugins](https://github.com/getpelican/pelican-plugins)에 남아 있다.

<br>

## 1.2 설치
### 방법 1 — pip 설치 (권장)
Pelican 4.5부터는 `pelican-` 네임스페이스 패키지로 배포되는 플러그인을 pip로 설치하면 **자동으로 등록**된다. 별도 설정이 필요 없다.

```shell
python -m pip install pelican-sitemap
python -m pip install pelican-neighbors
```

특정 플러그인만 골라 쓰고 싶다면 `pelicanconf.py`에 명시하면 된다. (명시하는 순간 자동 등록은 꺼진다)

```python
PLUGINS = ['sitemap', 'neighbors']
```

<br>

### 방법 2 — 저장소에 직접 내장
pip 패키지로 배포되지 않는 예전 플러그인은 저장소를 내려받아 프로젝트 안에 넣는다.

```shell
git clone --recursive https://github.com/getpelican/pelican-plugins
```

원하는 플러그인을 프로젝트 안으로 옮긴 뒤, 설정 파일인 `pelicanconf.py`에 아래 항목을 채운다.

```python
PLUGIN_PATHS = ['path/to/pelican-plugins']      # 플러그인 상위 경로
PLUGINS = ['sitemap', 'neighbors']              # 사용할 플러그인 목록
```

나는 테마 폴더 안에 플러그인을 내장해두고 아래 다섯 개를 사용했다.

* `sitemap`
* `representative_image`
* `share_post`
* `neighbors`
* `custom_article_urls`

<br>

# 2. 사용한 플러그인
플러그인을 내려받으면 각 플러그인 폴더의 `README.md`에 설정 방법이 자세히 적혀 있다.

## 2.1 sitemap
사이트맵을 생성해주는 플러그인이다. 설치하면 `url/sitemap.xml` 경로로 사이트맵을 볼 수 있다.

```python
PLUGINS = ['sitemap']

SITEMAP = {
    'format': 'xml'
}
```

자세한 설정은 [Sitemap 저장소](https://github.com/pelican-plugins/sitemap)에서 볼 수 있다.

> ### 💡 사이트맵이란?
> 검색엔진은 크롤러라는 로봇으로 웹 정보를 수집한다.
> 이때 크롤러가 사이트 구조를 쉽게 파악하도록 도와주는 것이 **사이트맵**이다.
>
> 사이트맵은 웹사이트의 구조를 크롤러가 찾기 쉽도록 정리한 XML 파일이다.
> 이름 그대로 웹사이트의 지도인 셈이다.

<br>

## 2.2 representative_image
글의 대표 이미지를 설정해주는 플러그인이다.

```python
PLUGINS = ['representative_image']
```

템플릿에서는 아래와 같이 쓸 수 있다.

```jinja
{% for article in articles_page.object_list %}
    {% if article.featured_image %}
        <img src="{{ article.featured_image }}"
             alt="{{ article.title|capitalize }} Preview Image">
    {% endif %}
{% endfor %}
```

<br>

## 2.3 share_post
작성한 글을 소셜 미디어에 공유할 수 있게 해주는 플러그인이다.

```python
PLUGINS = ['share_post']
```

템플릿에서는 아래와 같이 쓸 수 있다.

```jinja
{% if article.share_post %}
<ul>
    <li>
        <a href="{{ article.share_post['email'] }}"
           target="_blank" title="Share via Email">Email</a>
    </li>
    <li>
        <a href="{{ article.share_post['twitter'] }}"
           target="_blank" title="Share on Twitter">Twitter</a>
    </li>
    <li>
        <a href="{{ article.share_post['facebook'] }}"
           target="_blank" title="Share on Facebook">Facebook</a>
    </li>
    <li>
        <a href="{{ article.share_post['linkedin'] }}"
           target="_blank" title="Share on LinkedIn">LinkedIn</a>
    </li>
</ul>
{% endif %}
```

공식적으로는 `facebook`, `email`, `twitter`, `diaspora`, `linkedin`, `hacker-news`, `reddit`을 지원한다.

아쉬운 점은 레퍼런스가 해외 기준이다 보니 국내에서 많이 쓰는 소셜(Instagram, KakaoTalk 등)이 없다는 것이다. 😢

<br>

## 2.4 custom_article_urls
글의 경로를 바꿀 수 있는 플러그인이다.

기존에는 루트에 생성되던 파일에 카테고리로 구분되는 경로를 추가해주었다.

* 기존: `https://localhost:8000/create-pelican-site.html`
* 변경: `https://localhost:8000/posts/pelican/create-pelican-site.html`

```python
PLUGINS = ['custom_article_urls']

CUSTOM_ARTICLE_URLS = {
    'Category 1': {
        'URL': '{category}/{slug}.html',
        'SAVE_AS': '{category}/{slug}.html'
    }
}
```

<br>

## 2.5 neighbors
글의 이전/다음 포스트를 알려주는 플러그인이다.

```python
PLUGINS = ['neighbors']
```

템플릿에서는 아래와 같이 쓸 수 있다.

```jinja
<ul>
    {% if article.prev_article %}
        <li>
            <a href="{{ SITEURL }}/{{ article.prev_article.url }}">
                {{ article.prev_article.title }}
            </a>
        </li>
    {% endif %}
    {% if article.next_article %}
        <li>
            <a href="{{ SITEURL }}/{{ article.next_article.url }}">
                {{ article.next_article.title }}
            </a>
        </li>
    {% endif %}
</ul>
```

같은 카테고리 안에서의 이전/다음 글은 `prev_article_in_category`,
`next_article_in_category`로 가져올 수 있다.
