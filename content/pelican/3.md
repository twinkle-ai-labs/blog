# 들어가며
`Pelican`은 `Jinja` 템플릿 엔진을 기반으로 동작한다.

그래서 테마를 손보려면 Jinja를 알아야 한다.
이 글에서는 Jinja 문법을 정리한다.

---

# 1. 템플릿
## 1.1 템플릿 엔진
### 정의
> ### 템플릿 엔진
>
> 템플릿 프로세서(템플릿 엔진 또는 템플릿 파서라고도 한다)는 템플릿과 데이터(데이터 모델로 정의된)를 결합해 문서나 프로그램을 만들어내는 소프트웨어다.


## 1.2 Jinja
Pelican은 `jinja` 템플릿 엔진을 기반으로 한다.

> ### Jinja
> ![Jinja Logo]({static}/images/pelican/jinja.svg)
>
> Jinja는 Python을 위한 웹 템플릿 엔진이다.
>
> **Armin Ronacher**가 만들었고 **BSD** 라이선스를 따른다.
>
> Django 템플릿 엔진과 비슷하지만, 샌드박스 안에서 평가되면서도 Python에 가까운 표현식을 쓸 수 있다.
>
> 텍스트 기반 템플릿 언어이므로 마크업뿐 아니라 어떤 소스 코드든 생성할 수 있다.

<br>

나는 Pelican `v.4.9.1`을 설치했다.

> ### 버전 정보
> * pelican: 4.9.1
> * Jinja: 3.1.2

더 자세한 내용은 [Jinja 공식 문서](https://jinja.palletsprojects.com/en/3.1.x/)에서 볼 수 있다.

# 2. Jinja 문법

Jinja에는 세 종류의 구분자(delimiter)가 있다.

> ### 구분자
> * `{% ... %}` — **문(Statement)** — 흐름 제어
> * `{{ ... }}` — **표현식(Expression)** — 값 출력
> * `{# ... #}` — **주석(Comment)** — 렌더링되지 않음

## 2.1 문 (Statements)

문은 조건, 반복, 템플릿 구조 등 템플릿의 흐름을 제어한다.

### if

```jinja
{% if articles %}
    <p>{{ articles|length }} posts</p>
{% elif drafts %}
    <p>only drafts here</p>
{% else %}
    <p>no posts yet</p>
{% endif %}
```

### for

```jinja
<ul>
{% for article in articles %}
    <li>{{ article.title }}</li>
{% endfor %}
</ul>
```

반복문 안에서는 Jinja가 특별한 `loop` 변수를 제공한다.

> ### loop 변수
> * `loop.index` — 현재 반복 횟수 (1부터 시작)
> * `loop.index0` — 현재 반복 횟수 (0부터 시작)
> * `loop.first` / `loop.last` — 불리언
> * `loop.length` — 전체 항목 수

### set

```jinja
{% set total = articles|length %}
<span>{{ total }} notes</span>
```

## 2.2 표현식 (Expressions)

표현식은 값을 문서에 출력한다. 점(`.`)으로 속성에 접근하고, 파이프(`|`)로 **필터**를 걸어 값을 변형한다.

```jinja
{{ article.title }}
{{ article.title|upper }}
{{ article.summary|striptags|truncate(80) }}
{{ articles|length }}
```

자주 쓰는 필터:

> ### 필터
> * `length` — 항목 개수
> * `upper` / `lower` / `capitalize` — 대소문자 변환
> * `striptags` — HTML 태그 제거
> * `truncate(n)` — 문자열을 `n`자에서 자르기
> * `default('value')` — 값이 정의되지 않았을 때의 기본값
> * `join(', ')` — 리스트를 문자열로 합치기

## 2.3 주석 (Comments)

주석은 렌더링 시점에 제거되어 결과 HTML에 아무것도 남지 않는다.

```jinja
{# This line never reaches the browser #}
```

템플릿이 **왜** 그렇게 동작하는지를 방문자에게 노출하지 않고 남겨두기에 좋다.

# 3. 템플릿 상속

Jinja의 진짜 힘은 상속에 있다. 베이스 템플릿이 **블록**을 선언하면,
자식 템플릿은 필요한 부분만 덮어쓴다.

`base.html`:

```jinja
<html>
<head><title>{% block title %}Twinkle Blog{% endblock %}</title></head>
<body>
    {% block content %}{% endblock %}
</body>
</html>
```

`article.html`:

```jinja
{% extends "base.html" %}

{% block title %}{{ article.title }} - {{ super() }}{% endblock %}

{% block content %}
    <article>{{ article.content }}</article>
{% endblock %}
```

> ### 상속 키워드
> * `{% extends %}` — 부모 템플릿을 상속
> * `{% block %}` — 자식이 덮어쓸 수 있는 영역 정의
> * `{{ super() }}` — 부모 블록의 내용을 렌더링
> * `{% include %}` — 다른 템플릿을 그대로 포함

Pelican 테마도 정확히 이 방식으로 만들어진다 — 모든 페이지 템플릿이
`base.html`을 상속하고 자신의 `content` 블록을 채운다.

# 마치며

Pelican 테마를 읽고 고치는 데 필요한 Jinja는 이게 전부다.
흐름을 제어하는 문, 필터로 값을 출력하는 표현식, 구조를 잡는 상속.
이제 테마의 `templates/` 폴더를 열고 직접 만져보자.
