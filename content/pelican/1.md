# 1. Pelican이란?
![Pelican Logo]({static}/images/pelican/pelican-preview.gif)

Pelican은 Python으로 만들어진 **정적 사이트 생성기(Static site generator)**다.<br>
“Pelican”은 프랑스어로 “공책”을 뜻하는 calepin의 애너그램이다.

더 자세한 내용은 [Pelican 공식 사이트](https://getpelican.com/)에서 볼 수 있다.


<br>


# 2. Pelican 빠르게 시작하기
## 2.1 의존성 설치
> ### 💡 사전 준비
> Pelican은 Python 기반이므로 Python이 먼저 설치되어 있어야 한다. 아래 명령이 동작하는지 확인하자.
>
> * `python`
> * `pip`

먼저 프로젝트마다 격리된 환경을 쓰도록 가상 환경을 만든다.

```shell
# create & activate virtual environment
python -m venv .venv
source .venv/bin/activate
```

공식 문서에서 권장하는 방식대로 Markdown 지원을 포함해 설치한다.

```shell
# core library with markdown support
python -m pip install "pelican[markdown]"

# (optional) typogrify for typographically-improved HTML
python -m pip install typogrify
```

<br>

## 2.2 프로젝트 생성
아래 명령을 순서대로 실행한다.

```shell
# make folder for project
mkdir pelican-demo

# move to folder
cd pelican-demo

# initialize folder for Pelican project
pelican-quickstart
```

## 2.3 프로젝트 구조
`pelican-quickstart`로 만든 프로젝트는 아래와 같은 구조를 갖는다.

```txt
yourproject/
├── content			# 글을 쓰는 디렉터리
│   └── (pages)
├── output			# 빌드 결과 디렉터리
├── tasks.py			# 설정 및 실행 코드
├── Makefile			# 빌드 파일
├── pelicanconf.py		# 메인 설정 파일
└── publishconf.py		# 배포할 때 사용하는 설정
```

새 글을 쓰려면 `content` 디렉터리에 `.md` 파일을 새로 만들면 된다.

<br>

## 2.4 명령어
### 빌드 ⚡
빌드한 뒤에 프로젝트를 실행할 수 있다.

```shell
# default command
pelican

# command with [path]
pelican content

# command with [path] [-o output_directory] [-s setting_file] [-t template_directory]
pelican content -o output -s publishconf.py -t themes/twinkle
```

<br>

### 실행 🔥
```shell
pelican --listen
```

개발할 때는 파일이 바뀔 때마다 자동으로 다시 빌드되도록 `-r`(autoreload)을 함께 쓰는 게 편하다.

```shell
# autoreload + local server (http://localhost:8000)
pelican -r -l
```
