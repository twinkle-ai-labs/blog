물타기 계산기의 기능을 정리한 뒤, 앱 소개 페이지와 Play 스토어 설명을 다시 살폈습니다. 소개 페이지에서는 실제 화면과 기능이 잘 드러나지 않았고, 스토어 설명에는 코인이나 해외 주식 계산에 사용할 수 있다는 내용이 부족했습니다.

2026년 9월 11일에 수정한 소개 화면과 스토어 문구를 기록합니다.

## 앱 소개 페이지에 별도 스타일을 적용했습니다

`/app/stock-calculator`는 Aurora Ledger의 공통 배경과 목록 스타일을 사용하고 있었습니다. 사이트의 일관성을 유지하기에는 편했지만, 앱의 화면과 기능을 소개할 때는 다른 배치가 필요하다고 판단했습니다.

그래서 이 페이지의 `door.module.css`에 Midnight/Glass 다크 테마를 구성했습니다. 공통 토큰 대신 소개 페이지 안에서 사용할 색과 효과를 별도로 정한 작업입니다.

히어로 제목에는 `clamp`로 화면 폭에 따라 달라지는 큰 글자를 적용하고, 뒤에는 앱 색상의 후광을 넣었습니다. 기능을 나열하던 텍스트 목록은 배경이 비치는 2단 카드 그리드로 바꿨습니다. 기능마다 설명 영역을 확보하려는 목적이었습니다.

### 폰과 폴더블 화면을 함께 보여줬습니다

태블릿과 폴더블 레이아웃도 소개 페이지에서 볼 수 있게 했습니다. 기존 스크린샷 데이터는 경로 문자열만 담고 있었으므로 `{ src, type: "phone" | "wide" }` 형태로 바꿨습니다.

화면 종류에 맞는 폭으로 이미지를 배치하고, 가로로 넘기면 스냅되는 영역을 만들었습니다. 방문자가 폰 화면뿐 아니라 넓은 화면의 배치도 직접 확인할 수 있게 됐습니다.

## 스토어 설명에 사용 범위를 적었습니다

앱은 국내·해외 주식과 코인의 평단가를 계산하고, 계산한 시나리오를 이미지로 공유할 수 있습니다. 이전 설명은 ‘계산기를 두드리는 번거로움을 덜어드립니다’에 머물러 이런 사용 범위가 충분히 드러나지 않았습니다.

ASO(App Store Optimization) 작업으로 Python 스크립트를 작성해 11개 지원 로케일의 `title.txt`, `short-description.txt`, `full-description.txt`를 수정했습니다. 가상화폐, 암호화폐, 코인, 해외 주식이라는 표현을 설명에 반영했습니다. 이미지 공유 기능도 계산 결과를 다른 사람에게 전달할 수 있다는 용도로 더 구체적으로 소개했습니다.

이 작업에서 확인한 것은 문구와 등록정보의 변경입니다. 검색 노출이나 설치 전환이 얼마나 달라졌는지는 이 기록으로 판단할 수 없습니다.

### 제목과 짧은 설명의 길이를 검사했습니다

당시 Play 등록정보의 제한은 제목 최대 30자, 짧은 설명 최대 80자였습니다. 한국어에서 맞춘 길이가 스페인어나 독일어 번역에서는 한도를 넘는 경우가 있었습니다.

`./gradlew testDebugUnitTest --tests "*StoreListingTest*"`를 실행해 11개 언어의 글자 수를 검사했습니다. 키워드를 추가하면서도 각 항목이 제한 안에 들어오는지 확인하는 검사였습니다.

앱 개발에 2주, 출시 준비에 2주를 쓴 뒤 이날 테스트 트랙에서 프로덕션으로 전환해 전체 공개했습니다.
