디자인 시스템 목업을 열었다가 이상한 걸 봤다.

```css
/* Aurora 는 #7040D9 */
--brand: #6F3DE0;
```

**주석 바로 아래에서 다른 값이 그려지고 있었다.**

이 문서는 디자인 시스템을 설명하는 문서다.
그 문서 자신의 브랜드색이 자기가 설명하는 값과 달랐다.

---

# 색 표가 여섯 벌 있었다

세어 보니 이랬다.

| 벌 | 언제 이기나 |
|---|---|
| `:root` (라이트) | 기본 |
| `@media (prefers-color-scheme: dark)` | 시스템이 다크일 때 |
| `[data-theme="dark"]` | 사용자가 다크를 고를 때 |
| `[data-theme="light"]` | 사용자가 라이트를 고를 때 |
| `.phone` 스킨 × 3 | 목업 안의 폰 목업 |

같은 값의 표가 **여섯 벌.**

그중 뒤에 온 블록 하나가 옛 보라(`#6F3DE0`)를 들고 있었고,
CSS는 뒤에 온 것이 이기므로 그게 화면에 나왔다.

---

# 진짜 문제는 «고칠 자리가 몇 개인지 모르게 되는 것»

같은 값을 여러 자리에 적으면 흔히 「그중 하나를 고치는 걸 잊는다」고 말한다.
실제로 일어나는 일은 좀 다르다.

**고칠 자리가 몇 개인지를 모르게 된다.**

`#6F3DE0`을 지우려고 검색하면 몇 개가 나올지 모른다.
전부 고쳤는지 확인할 방법도 없다. 화면을 봐도 지금 보고 있는 테마만 보인다.

그리고 이게 테마 블록의 고약한 점이다.

> 라이트로 **직접 골랐을 때만** 틀린 값은,
> 시스템 다크로 개발하는 동안 영영 안 보인다.

`[data-theme="light"]` 블록은 사용자가 토글을 눌러 라이트를 고를 때만 적용된다.
시스템이 라이트여도 `:root` 기본값이 쓰이므로 이 블록은 안 탄다.
**개발자가 그 조합을 일부러 만들지 않으면 평생 안 보는 코드**다.

---

# `light-dark()`로 한 벌이 됐다

CSS에 `light-dark()`가 있다. 값 하나에 라이트·다크 두 값을 같이 적는다.

```css
:root {
  color-scheme: light dark;

  --token-bg:      light-dark(#F8F6FC, #110D19);
  --token-text:    light-dark(#21182D, #FAF7FF);
  --token-primary: light-dark(#7040D9, #986CF4);
}
```

어느 쪽을 쓸지는 그 요소의 **`color-scheme`이 정한다.**
그러니 테마를 직접 고르는 자리는 이 한 줄이면 끝이다.

```css
:root[data-theme="dark"]  { color-scheme: dark; }
:root[data-theme="light"] { color-scheme: light; }
```

미디어 쿼리도 없고, 특정도 싸움도 없다. **표는 한 벌이다.**

## 짧은 이름이 필요하면 가리키게 둔다

화면 안에서 `--token-bg`가 길면 짧은 이름을 두고 싶어진다.
그때 값을 옮겨 적으면 두 벌이 된다.

```css
/* ✗ 두 벌이 된다 */
--bg: #F8F6FC;

/* ○ 가리킨다 */
--bg: var(--token-bg);
```

---

# `color-scheme`의 덤이 크다

`color-scheme`은 «어느 값을 고를까»만 정하는 게 아니다.
브라우저가 그리는 것들의 색이 따라온다.

- 스크롤바
- 폼 컨트롤 (`<input>`, `<select>`, 체크박스…)
- 첫 캔버스(페이지 배경이 칠해지기 전의 바탕)

이 선언을 빼면 브라우저는 페이지가 라이트라고 믿는다.
그래서 **공들여 만든 어두운 판 옆에 은색 스크롤바를 세운다.**

그건 「다크를 지원한다」가 아니라 「다크를 잊었다」로 읽힌다.

주의할 게 하나 있다. 이 값은 테마를 stamp하는 **루트 요소**에 얹어야 한다.
`body`에만 걸면 뷰포트 스크롤바는 따라오지 않는다 — 캔버스는 루트의 것을 본다.

# 정리

- 색은 `light-dark()` **한 줄**로 적는다.
- 짧은 이름이 필요하면 **가리키게** 두지 옮겨 적지 않는다.
- 테마를 직접 고르는 자리는 `color-scheme`만 못 박는다.
- `color-scheme`을 루트에 선언한다 — 스크롤바와 폼 컨트롤이 딸려 온다.

한 벌은 한 번만 적는다. 두 벌이 되는 순간, 둘이 언제 달라졌는지 아무도 모른다.
